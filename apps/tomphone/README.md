# Tomphone

Tomphone is a compact Qt 6 desktop SIP softphone. It uses Baresip for SIP/audio calls and stores account settings in a user-owned configuration file.

This copy is packaged for Ubuntu as a Debian `.deb` by the Tom OS build. It is a SIP softphone, not a mobile-to-mobile data transfer tool.

Dependencies: Qt 6 Quick/Controls, Baresip with its PulseAudio module, and a PulseAudio-compatible audio service such as PipeWire.
