PUNKSWAY — QUICKSTART
=====================

PunkHyprland is an Ubuntu-based live desktop project targeting Hyprland with Caelestia Shell. Hyprland is the only supported window manager session.
The default look follows the supplied Tom OS reference: neon blue/cyan and violet wallpaper, translucent Caelestia panels, five workspaces and rounded surfaces. If Caelestia is installed, the wallpaper drives its dynamic colour scheme; otherwise Waybar/Wofi provide a fallback. Caelestia is not prebuilt into this ISO yet.

APPS
----
The Wofi launcher lists installed desktop applications. The dock shortcuts open the file manager, terminal and app launcher. The volume module opens pavucontrol.

TERMINAL
--------
Zsh is the default shell. Interactive terminals show the custom Tom OS Fastfetch ASCII logo and system summary. Edit ~/.zshrc to customise the prompt or Fastfetch settings in ~/.config/fastfetch/config.jsonc.

DISPLAY MANAGER RECOVERY\n-------------------------\nIf the system boots to a text console instead of the graphical login, log in and run:\n  sudo /usr/local/sbin/fix-display-manager\nThen reboot. The build sets graphical.target and enables SDDM, but the final image still needs a VM boot test.\n\nLIVE SESSION VS INSTALLED SYSTEM
--------------------------------
Ly is the configured display/login manager and presents a TTY-based session selector. Choose the Hyprland session. Automatic live-session login has been disabled because the previous LightDM-specific autologin hook does not apply to Ly. User defaults are copied from
/etc/skel during account creation.

INSTALLING
----------
The ISO is based on Ubuntu 26.10 Desktop and retains the Ubuntu installer
from the source image. Hyprland/Caelestia integration is experimental and is not yet verified. Test in a virtual machine first. Back up important files
before installing an operating system to a physical disk.

BUILDING
--------
On Omarchy Linux install Podman with pacman, then run:
  ./build.sh /path/to/ubuntu-26.10-desktop-amd64.iso

A Tom OS neon purple/cyan Plymouth splash and progress bar are configured for boot. The progress bar follows Plymouth's boot progress callbacks; verify it in a VM.

The base image should be the official Ubuntu 26.10 Desktop amd64 ISO. The build installs `linux-generic` and checks for a Linux 7.3 generic kernel image before repacking. It also compiles Tomphone from `apps/tomphone/`, packages it as `tomphone_0.1.0_amd64.deb`, and installs the package into the live filesystem.
